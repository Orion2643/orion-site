# ⚙️ Instalação

Clone o projeto

```bash
git clone https://github.com/Orion2643/orion-site.git
```

Entre na pasta

```bash
cd orion-site
```

Instale as dependências

```bash
npm install
```

Execute o projeto

```bash
npm run dev
```

---

# 🏗 Build

```bash
npm ci

npm run build
```

---

# ☁️ Processo Oficial de Deploy

Sempre seguir este fluxo:

```bash
npm ci

npm run build

git status

git add .

git commit -m "Descrição da alteração"

git push origin main
```

Após o Push:

✅ GitHub recebe o código

↓

✅ Cloudflare inicia o Deploy

↓

✅ Site publicado automaticamente
